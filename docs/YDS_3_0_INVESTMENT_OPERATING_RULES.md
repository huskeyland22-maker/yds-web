# YDS 3.0 투자전략 — 최종 운영 규칙

**문서 상태:** 운영 규칙 확정본 (제품 코드 미반영)  
**관련 초안:** `docs/YDS_3_0_INVESTMENT_STRATEGY_DRAFT.md`  
**작성 목적:** 매월 실제로 무엇을 할지 한 장으로 고정한다.

> 본 문서는 **운영 규칙만** 정의한다.  
> 기존 Panic Index, `/market-analysis`, Crash Reserve, Track Record/Ledger 등 **기존 기능은 변경·삭제·강제 연결하지 않는다.**

---

## 1. 투자 원칙

1. **10년 이상 장기투자**를 전제로 한다.
2. **미국 대표지수에 연동된 국내상장 ETF**를 **연금계좌**에서 적립식 투자한다.
3. YDS는 **저점을 예측하지 않는다.** 기본 적립을 멈추게 하지 않는다.
4. 시장이 하락했을 때, **이미 확보된 Reserve**로만 투자 강도를 높일 수 있게 **안내**한다.
5. **자동매매가 아니다.** 매수 주문을 실행하지 않는다.
6. **ETF별 비중·배분은 YDS가 정하지 않는다.** 사용자가 매월 직접 판단한다.
7. YDS는 **전체 투자 강도와 총 투자금액**만 계산·제시한다.
8. 이번 전략의 매수 강도는 **S&P500 주봉 MA40**만 사용한다.  
   기존 8대 공포지수·MACD·RSI는 **이 전략의 투자강도 트리거로 쓰지 않는다.**

| 구분 | 금액 |
|------|------|
| 계좌당 월 기본 | 100,000원 |
| 월 기본 합계 | **300,000원** |

- 기본 투자금은 **시장 상황과 관계없이 계속** 투자한다.
- 단계가 1.0배여도 월 30만 원은 적립한다.

화면/안내에 항상 다음을 명시한다.

> **「ETF별 투자금 배분은 사용자 판단」**

## 3. 시장 판단 기준

| 항목 | 규칙 |
|------|------|
| 기준 | S&P500 **주봉** |
| 이동평균 | **40주 이동평균 (MA40)** |
| 판정 시점 | **매월 투자 직전** |
| 사용 봉 | **가장 최근 완료된 주봉**만 |
| 금지 | **진행 중인(미완료) 주봉** 사용 금지 |

비교값:

\[
\text{낙폭} = \frac{\text{완료 주봉 종가} - \text{MA40}}{\text{MA40}}
\]

(음수일수록 MA40 대비 하락)

---

## 4. 투자 강도 표

S&P500 **완료 주봉 종가**가 MA40 대비:

| 조건 | 배수 | 의미 |
|------|------|------|
| MA40보다 **5% 미만** 하락 (낙폭 &gt; −5%) | **1.0배** | 기본만 |
| MA40 대비 **−5% 이하** | **1.25배** | 소폭 증액 |
| MA40 대비 **−10% 이하** | **1.5배** | 중간 증액 |
| MA40 대비 **−20% 이하** | **2.0배** | 최대 증액 |

### 경계값 규칙

- 경계에 **정확히** 걸리면 **더 낮은 가격(더 센 배수) 단계**를 적용한다.
- 예: 낙폭이 정확히 **−5%** → **1.25배**  
- 예: 낙폭이 정확히 **−10%** → **1.5배**  
- 예: 낙폭이 정확히 **−20%** → **2.0배**

### 사용하지 않는 것 (이번 전략)

- 기존 8대 공포지수 → **매수 트리거 아님**
- MACD → **투자강도 결정에 사용 안 함**
- RSI → **핵심 투자강도 결정에 사용 안 함**
- 1주 유지 / 2주 확인 조건 → **추가하지 않음**
- 월중 급락 자동 추가매수 → **하지 않음** (월 1회 판단)

기존 Panic Index·`/market-analysis`는 **별개 기능으로 보존**한다.

## 5. 기본 투자금 · 추가 투자금 · Reserve

### 5.1 기본 vs 추가

| 구분 | 규칙 |
|------|------|
| 기본 투자금 | **항상** 300,000원 (계좌당 10만 × 3) |
| 목표 총액 | `300,000 × 배수` |
| 목표 추가액 | `목표 총액 − 300,000` |
| 실제 추가액 | **보유 Reserve와 목표 추가액 중 작은 값** |
| 최종 총액 | `기본 + 실제 추가` |

### 5.2 Reserve 운영

1. 소득이 일정하지 않으므로 **연간 Reserve를 미리 의무 확보하지 않는다.**
2. **여유자금이 생겼을 때만** Reserve로 보관한다.
3. 백테스트의 「연간 기본투자액 50% Reserve」는 **연구 참고값**일 뿐, **운영 의무가 아니다.**
4. Reserve가 **부족**하면 **가능한 범위까지만** 추가 투자한다.
5. Reserve가 **0**이면 추가 투자금은 **0원**이다. (배수가 1.25·1.5·2.0이어도 추가는 0)
6. 시장이 낮다는 이유만으로 **사용자가 돈을 더 마련하도록 요구·권유하지 않는다.**

### 5.3 목표 총액 예시 (Reserve가 충분할 때)

월 기본 300,000원 기준:

| 배수 | 목표 총 투자금 | 목표 추가 (Reserve에서) |
|------|----------------|-------------------------|
| 1.0 | 300,000원 | 0원 |
| 1.25 | 375,000원 | 75,000원 |
| 1.5 | 450,000원 | 150,000원 |
| 2.0 | 600,000원 | 300,000원 |

실제 추가금은 **보유 Reserve를 초과할 수 없다.**

## 6. 계산 예시

### 예시 A — 1.0배, Reserve 있음

- 완료 주봉: MA40 대비 −3% → **1.0배**
- 기본 300,000 / 추가 0 / **최종 총액 300,000원**
- ETF 배분: 사용자 판단

### 예시 B — 1.25배, Reserve 충분 (예: Reserve 200,000)

- 낙폭 −5% → **1.25배**
- 목표 총액 375,000 / 목표 추가 75,000
- 실제 추가 min(75,000, 200,000) = **75,000**
- **최종 총액 375,000원**

### 예시 C — 1.5배, Reserve 부족 (예: Reserve 50,000)

- 낙폭 −12% → **1.5배**
- 목표 총액 450,000 / 목표 추가 150,000
- 실제 추가 min(150,000, 50,000) = **50,000**
- **최종 총액 350,000원** (기본 30만 + Reserve 한도 내 5만)
- 부족한 10만을 “마련하라”고 **안내하지 않음**

### 예시 D — 2.0배, Reserve 0

- 낙폭 −22% → **2.0배**
- 목표 총액 600,000이어도 실제 추가 = **0**
- **최종 총액 300,000원** (기본만)

## 7. YDS가 보여주는 것

구현 시(아직 코드 미반영) YDS는 최소 다음을 표시한다.

| 항목 | 설명 |
|------|------|
| MA40 대비 위치 | 완료 주봉 종가 vs MA40 (%) |
| 적용 단계 | 1.0 / 1.25 / 1.5 / 2.0 |
| 투자 강도 배수 | 위와 동일 |
| 이번 달 기본 투자금 | 300,000원 |
| 이번 달 목표 총 투자금 | 기본 × 배수 |
| Reserve에서 사용 가능 추가 | 보유 Reserve |
| 최종 추가 투자금 | min(목표 추가, Reserve) |
| 최종 총 투자금 | 기본 + 최종 추가 |

필수 문구:

> **ETF별 투자금 배분은 사용자 판단**

YDS가 **하지 않는 것:**

- ETF별 금액 자동 배분  
- 증권사 주문 실행  
- 공포지수/MACD/RSI로 이번 전략 배수 결정  
- Reserve 강제 적립 요구

## 8. 데이터 오류·신뢰성 처리

1. **최근 완료 주봉이 없거나 신뢰할 수 없으면** 투자강도를 **임의 계산하지 않는다.**
2. 데이터가 **오래되었거나 비정상**이면 화면에 **명확히 표시**한다. (예: STALE / 데이터 확인 필요)
3. 오류·결측을 **0으로 치환해 배수 계산하지 않는다.**
4. **데이터 신뢰성 &gt; 투자금 계산** — 신뢰할 수 없으면 금액 제시보다 “판단 불가/보류”를 우선한다.
5. 진행 중 주봉으로 앞당겨 계산하지 않는다.

---

## 9. 월간 운영 절차 (사용자가 할 일)

매월 **한 번**, 투자 직전에:

1. **완료된** 최신 S&P500 주봉·MA40 위치를 확인한다. (YDS가 제공하면 그 값을 본다)
2. 위 **투자 강도 표**로 배수(1.0 / 1.25 / 1.5 / 2.0)를 확인한다.
3. **기본 30만 원**은 세 계좌에 적립할 준비를 한다. (계좌당 10만)
4. Reserve 잔액을 확인한다.  
   - 있으면: 목표 추가와 Reserve 중 작은 금액을 **추가**로 쓴다.  
   - 없으면: **기본만** 한다.
5. **최종 총액**을 ETF 세 종목에 **본인이 배분**해 매수한다.  
   (비중은 YDS 지시가 아님)
6. 월중에 급락해도 **자동·추가 월중 매수는 하지 않는다.** 다음 달 정기 판단까지 기다린다.
7. 여유자금이 생기면 (의무 없이) Reserve에 넣어 둔다.
