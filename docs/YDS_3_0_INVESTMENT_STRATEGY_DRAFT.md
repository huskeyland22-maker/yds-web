# YDS 3.0 투자전략 설계 초안

**문서 상태:** 최종 승인 후보 (제품 코드 미반영)  
**작성 근거:** 1~3차 연구용 백테스트 (지수 프록시, 제품 미구현)  
**작성일:** 2026-09-09  

> 본 문서는 설계 초안이다. 기존 YDS 웹·공포지수·Crash Reserve·API·DB를 변경하지 않는다.

---

## 1. 투자철학

YDS의 투자 방향은 다음으로 전환한다.

| 이전 방향(개념) | YDS 3.0 방향 |
|-----------------|--------------|
| 공포지수로 저점을 잡는 전략 | 장기 적립식 + 시장 하락 시 투자금 증액 |

### 핵심 문장 (필수)

- **YDS는 저점을 예측하는 시스템이 아니다.**
- **YDS는 장기 적립을 멈추게 하는 시스템이 아니다.**
- **YDS는 시장이 하락했을 때 미리 확보된 여유자금을 더 적극적으로 투입할 수 있도록 투자 강도를 알려주는 도구다.**
- **YDS는 ETF별 매수 결정을 대신하지 않는다.**
- **YDS는 자동매매 시스템이 아니다.**
- **최종 투자 판단은 사용자에게 있다.**

### 목표

복잡한 투자 시스템보다, **10년 이상 실제로 사용할 수 있는 단순한 시스템**을 우선한다.

### 기본 원칙

1. 저점을 정확히 맞히지 않는다.
2. 시장이 좋든 나쁘든 **기본 적립은 계속**한다.
3. 시장이 많이 눌렸을 때만 **추가 투자**한다.
4. 추가 투자는 실제 여유자금으로 확보된 **Reserve 안에서만** 한다.
5. 생활비·필수자금을 투자에 사용하지 않는다는 전제를 둔다.
6. YDS는 매수를 **강제하지 않는다**.
7. 최종 투자 판단은 **사용자가** 한다.

---

## 2. 계좌

총 **3개 계좌**.

| # | 계좌 | 역할 |
|---|------|------|
| 1 | 본인 연금저축계좌 | 본인 장기 적립 |
| 2 | 자녀 1 계좌 | 자녀 장기 적립 |
| 3 | 자녀 2 계좌 | 자녀 장기 적립 |

- **3개 계좌 모두 동일한 시장 단계·배수 규칙**을 사용한다.
- 계좌별 **금액 자체**는 향후 변경 가능하도록 설계한다. (규칙만 공유, 금액은 설정값)

---

## 3. 기본 투자금

| 구분 | 금액 |
|------|------|
| 계좌별 기본 월 투자금 | 100,000원 |
| 전체 월 기본 적립 | 300,000원 |
| 연간 기본 적립 | 3,600,000원 |

- 기본 투자금은 시장 상태와 관계없이 **항상 유지**한다.
- NORMAL이어도 월 기본 적립(계좌당 10만 원)은 한다.

## 4. ETF

현재 투자 대상 ETF:

1. **TIGER 미국S&P500**
2. **TIGER 미국나스닥100**
3. **ACE 미국빅테크7**

- 시장 단계 계산의 **기준 지수**는 S&P500(주봉 MA40)이다.
- NASDAQ100·빅테크7에 **별도 시장 단계 계산을 만들지 않는다.**

---

## 5. ETF 비중 결정 방식

### YDS가 하지 않는 것

- ETF 비중 자동 결정
- ETF별 별도 매수 신호
- S&P500 / NASDAQ100 / 빅테크7별 **다른 배수**
- 빅테크7 전용 과매도 신호
- 자동 리밸런싱
- ETF별 매수금액 자동 배분

### YDS가 하는 것 (여기까지)

- **이번 달 총 투자 가능 금액**을 제시한다.

### 사용자가 하는 것

- 제시된 총액을 **3개 ETF에 원하는 비율로 직접 배분**한다.

**이유:** 비중은 위험 선호·목표·세금·계좌 특성에 따라 달라지며, 자동 배분은 복잡도와 오판 위험을 키운다. YDS는 **투자 강도(총액)** 만 단순하게 돕는다.

---

## 6. 시장 판단 기준

| 항목 | 내용 |
|------|------|
| 기준 지수 | S&P500 (단일) |
| 봉 | **주봉** (완료된 주만) |
| 지표 | **MA40** |
| 핵심 값 | MA40 대비 괴리율(%) |

### 괴리율

```text
(현재 주봉 종가 / MA40 - 1) × 100
```

예:

- MA40보다 5% 아래 → **-5%**
- MA40보다 10% 아래 → **-10%**
- MA40보다 20% 아래 → **-20%**

### 제외 (v1 배수 계산)

- **MACD:** 투자 배수 계산에서 제외
- **RSI:** v1 배수 계산에서 제외 (향후 참고지표 가능)

즉 현재 핵심 계산은:

**S&P500 + 주봉 + MA40 + MA40 대비 괴리율**

---

## 7. 투자 단계

> 아래 숫자는 1~3차 백테스트 기반 **최종 승인 후보**이다.  
> “제품 최종 확정”이 아니며, 승인 후 코드에 반영한다.

| 단계 | 조건 (MA40 대비 괴리율) | 의미 |
|------|-------------------------|------|
| NORMAL | **-5% 초과** | 정상 적립 |
| 조정 | **-5% 이하** | 완만한 눌림 |
| 저점권 | **-10% 이하** | 의미 있는 하락 |
| 강한 하락 | **-20% 이하** | 깊은 하락 |

경계 후보: **-5% / -10% / -20%**

---

## 8. 투자 배수

| 단계 | 배수 (승인 후보) |
|------|------------------|
| NORMAL | **1.0x** |
| 조정 | **1.25x** |
| 저점권 | **1.5x** |
| 강한 하락 | **2.0x** |

### 금액 해석 (계좌 합산 예시)

기본 월 합계 = 30만 원일 때:

| 단계 | 총 투자 가능 금액(개념) | 구성 |
|------|-------------------------|------|
| NORMAL | 30만 원 | 기본 30만 |
| 조정 | 37.5만 원 | 기본 30만 + 추가 7.5만 |
| 저점권 | 45만 원 | 기본 30만 + 추가 15만 |
| 강한 하락 | 60만 원 | 기본 30만 + 추가 30만 |

- **추가분**만 Reserve에서 충당한다.
- Reserve 잔액이 부족하면 **추가분만 잔액만큼** 제한한다. 기본 적립은 유지.

---

## 9. Reserve 운영

### 원칙

1. 수입이 불규칙하므로 **연초 강제 확보를 하지 않는다.**
2. 평소 여유자금이 생기면 Reserve로 확보한다.
3. 시장이 정상일 때 Reserve를 **사용하지 않는다.**
4. 시장이 눌렸을 때만 추가 투자에 사용한다.
5. **실제 Reserve 잔액보다 많은 추가투자를 하지 않는다.**
6. Reserve가 0원이면 추가투자 **0원**.
7. **기본 월 적립은 계속 유지**한다.

### 참고 목표 (강제 아님)

- 백테스트 참고: 연간 기본의 약 **50%**
- 3계좌 연 기본 360만 원 기준 → 참고 목표 **약 연 180만 원**
- 이는 “반드시 확보”가 아니라 **확보 목표의 참고치**다.
- 실제 운영은 **사용자가 확보한 Reserve 잔액**이 기준이다.

### 생활비

생활비·필수자금은 Reserve·투자에 넣지 않는다.

---

## 10. 월간 판정 방식

1. **매월 투자 직전**에 판단한다.
2. **완료된 최신 주봉**만 사용한다.
3. 미완료 주봉을 사용하지 않는다.
4. 그 달의 배수·총 투자 가능 금액을 다시 계산한다. (매월 재평가)
5. “단계 진입 후 N주 고정 유지” 같은 복잡한 홀딩 규칙은 v1에 두지 않는다.

### 단기 MA40 이탈

- 월 1회 판정이므로, 1주만 이탈했다가 회복하는 경우를 **별도 필터로 복잡하게 처리하지 않는다.**
- 기본안: 최신 완료 주봉 상태로 판단.
- 주간 투자로 확장할 때만 추후 **2주 확인 옵션**을 검토할 수 있다. (현재는 월간만)

### 월중 급락·월말 회복

- 월 1회 판정은 월중 V자 급락을 놓칠 수 있다.
- 이는 저점 추적이 아니라 **과투입 방지에 가까운 보수적 특성**으로 본다.
- v1에서는 월중 임시 추가 매수 자동 규칙을 두지 않는다.

## 11. 데이터 안전 규칙

| 규칙 | 내용 |
|------|------|
| 미래 날짜 금지 | 주봉 리샘플(`W-FRI` 등)이 **아직 오지 않은 금요일 라벨**을 만들지 않도록 처리 |
| 사례 | 2026-09-11 라벨은 원본 시세가 아니라 리샘플 아티팩트. 원본 일봉 마지막은 2026-09-09, 완료 주봉은 2026-09-04 |
| stale | S&P 주봉/일봉이 오래되면 **투자 강도 상향(증액)을 제시하지 않음** (표시는 가능) |
| 결측 | MA40 계산에 필요한 주봉이 부족하면 단계 = UNKNOWN, 배수 제안 보류 → **기본 적립만 안내** |
| 강제 매수 금지 | 데이터 이상 시에도 자동매수·강제 증액 없음 |

## 12. YDS가 결정하는 것

1. S&P500 완료 주봉 기준 MA40 괴리율
2. 현재 투자 단계 (NORMAL / 조정 / 저점권 / 강한 하락 / UNKNOWN)
3. 투자 배수 (1.0 / 1.25 / 1.5 / 2.0 후보)
4. 계좌별·전체 **이번 달 총 투자 가능 금액** 제안  
   (= 기본 × 배수, 단 추가분은 Reserve 잔액으로 상한)
5. Reserve 잔액 대비 추가 가능액 표시
6. (향후) 단계 변경 **정보 알림** — 매수 명령 아님

---

## 13. 사용자가 결정하는 것

1. 실제로 투자할지 여부
2. 제안 금액을 그대로 쓸지, 줄일지, 늘릴지
3. **3개 ETF 비중·배분**
4. Reserve에 얼마를 넣을지·언제 확보할지
5. 계좌별 기본 월 투자금 변경
6. 세금·계좌 한도·환헤지·상품 선택 등 실무 판단
7. 최종 매수 실행

---

## 14. YDS가 하지 않는 것

- 저점 예측 / “지금 사라” 명령
- 기본 적립 중단 지시
- 자동매매·자동주문·브로커 연동 주문
- ETF 비중 자동 결정·자동 리밸런싱
- ETF별 서로 다른 배수·별도 매수 신호
- MACD/RSI로 배수 결정 (v1)
- Reserve 강제 적립(연초 할당 강제)
- 생활비 투입 권유
- 기존 공포지수 시스템의 폐기·대체

---

## 15. 기존 공포지수 시스템 보존

**매우 중요.**

- 기존 공포지수(Panic Index) 관련 **웹·계산·API·DB·데이터**는 **폐기하지 않는다.**
- `/market-analysis`는 **그대로 유지**한다.
- 기존 Crash Reserve 코드·화면은 본 설계 초안 단계에서 **수정하지 않는다.**
- 현재 YDS 3.0 투자 배수 계산에는 공포지수를 **사용하지 않는다.**
- 향후 참고자료·별도 분석 기능으로 쓸 수 있으므로 **기능과 데이터를 보존**한다.
- 새 전략은 공포지수를 **대체하지 않고**, 장기 적립 가이드로 **병행 가능한 별도 축**으로 둔다.

---

## 16. 향후 모바일 알림

**현재 구현하지 않는다.** 설계상 “향후 기능”만 기록한다.

### 후보 트리거 (정보 알림)

- MA40 대비 **-5%** 진입 (조정)
- MA40 대비 **-10%** 진입 (저점권)
- MA40 대비 **-20%** 진입 (강한 하락)

### 알림 성격

- 매수 명령이 아니다.
- “투자 단계가 변경되었다”는 **정보 알림**이다.
- **동일 단계 반복 알림 방지** 방향으로 설계한다.

---

## 17. 최종 전략을 한 문장으로 표현

> **매월 기본 적립은 하고, S&P500 주봉이 MA40보다 많이 눌릴수록(대략 -5 / -10 / -20) 미리 확보해 둔 Reserve 안에서만 투자 강도를 올린다. ETF 비중과 최종 매수는 사용자가 정한다.**

## 18. 구현 전 최종 확인이 필요한 사항

| # | 항목 | 상태 |
|---|------|------|
| 1 | 경계값 -5 / -10 / -20 최종 승인 | 승인 후보 |
| 2 | 배수 1.0 / 1.25 / 1.5 / 2.0 최종 승인 | 승인 후보 |
| 3 | 4단계 유지 vs 3단계 축소 | 논의 가능 (현 후보=4단계) |
| 4 | 계좌별 기본 월 10만 원 확정 | 초안 확정에 가까움 (변경 가능 설계) |
| 5 | Reserve UI에 “참고 목표 연 180만” 표시 여부 | 미정 (강제 아님) |
| 6 | S&P 데이터 소스(일봉→주봉) 운영 경로 | 구현 시 결정 |
| 7 | stale 시 증액 제안 차단 기준(일수) | 구현 시 결정 |
| 8 | 기존 Crash Reserve / 홈 UI와의 배치·용어 정리 | 구현 단계에서 분리 설계 |
| 9 | 공포지수와 새 전략의 화면상 공존 방식 | 구현 시 (기존 기능 보존) |
| 10 | 모바일 알림 도입 시점 | 향후 |

## 부록 A. YDS가 결정하는 것 vs 사용자가 결정하는 것 (요약)

| YDS | 사용자 |
|-----|--------|
| 시장 단계·배수 | 투자 실행 여부 |
| 이번 달 총 투자 가능 금액 | ETF 비중·종목 배분 |
| Reserve 대비 추가 가능액 | Reserve 확보·규모 |
| (향후) 단계 변경 알림 | 최종 매수·금액 조정 |

## 부록 B. 연구 백테스트와의 관계

- 1~3차 백테스트는 **전략 검증용**이며 제품 코드에 자동 반영되지 않는다.
- 백테스트는 `^GSPC` 등 지수 프록시를 사용했다. 국내 ETF 실가격·괴리·환은 구현 전 별도 확인이 필요하다.
- 본 문서는 그 결과를 **운영 가능한 단순 규칙**으로 정리한 설계 초안이다.
